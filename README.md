# Erdian Aditiarna – Portfolio

React + Vite + Framer Motion. Colors: gray (main), black and white (secondary).

## Run locally
1. Install Node.js 18+ (https://nodejs.org)
2. `npm install`
3. `npm run dev` then open http://localhost:5173

## Build
`npm run build` (output in `dist/`), `npm run preview` to test it.

## Deploy to Vercel
1. Push to GitHub: `git init && git add . && git commit -m "init" && git branch -M main && git remote add origin <repo-url> && git push -u origin main`
2. vercel.com > Add New > Project > import the repo.
3. Framework Preset: Vite (auto). Build: `npm run build`. Output: `dist`. Click Deploy.
